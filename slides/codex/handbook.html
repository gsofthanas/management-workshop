インストール（フル手順）

今日使うのは Codex デスクトップアプリ。Windows / macOS に対応（Linux は今後）。ChatGPT の Plus / Pro 等のプランに含まれる。

Windows　Microsoft Store から入れる

Microsoft Storeストアで「Codex」を検索 → 入手（インストール）→ 起動

macOS　公式サイトから .dmg を入れる

ダウンロードdevelopers.openai.com/codex/app から .dmg（Apple Silicon / Intel）を入手 → 開いて Applications へドラッグ → 起動

起動確認

アプリが起動し、次項のサインイン画面が出れば導入は成功。

💡 CLI もある（任意）

Codex は同じ頭脳を アプリ / CLI（ターミナル）/ IDE拡張 / クラウド の4入口から使える。今日はアプリだけでよい。ターミナル派は npm install -g @openai/codex で CLI も入る。

サインイン

通常手順（アプリ）

  1. Codex アプリを起動する
  2. 「Sign in with ChatGPT」を選ぶ（普段の ChatGPT アカウント）
  3. ブラウザが開くのでログインし、アプリに戻る
  4. 作業フォルダを選ぶ（まずはホーム等でOK・本番の codextest は次で作る）
  5. 実行モードは Local を選ぶ（自分の PC 上で動かす）

💡 モデル・残量

既定モデルは GPT-5.5。残量やプランはアプリの表示で確認できる。

⚠️ APIキー

「Sign in with ChatGPT」を使う。APIキーは従量課金なので今日は使わない。認証情報はパスワード扱い——共有・コミット禁止。

コピペ用プロンプト集

まず1回動かす（codextest ウォームアップ）

① フォルダを作るC:\Users\自分\codextest を作って
② メモを書くcodextest に test.txt を作り「このフォルダは Codex の動作テスト用」と書いて
③ 表示するtest.txt を表示して

💡 開き直してから本番

この後、新しいセッションで codextest フォルダを開いてから、下の 3 呪文（本番）に進む。承認が出たら中身を見て OK。

売上 Excel → 集計 → レポートの 3 呪文

呪文 01 ― 売上データを作る架空の飲食店の売上を1週間・日別で、メニュー名/単価/数量の列入りの .xlsx を sales.xlsx に保存して
呪文 02 ― 読んで集計するsales.xlsx を読み、メニュー別・日別売上と売れ筋トップ5を新シート"集計"に。元は壊さずコピーに
呪文 03 ― レポートを作る"集計"を、棒グラフ（インラインSVG/canvas・外部CDN禁止）とサマリー付きの単一HTML report.html にしてブラウザで開いて

（任意）事務自動化

ファイルリネーム（使い捨てフォルダで実行）（使い捨てフォルダで）.jpg を日付順に vacation-001… にリネームして実行。標準ライブラリのみ

net-off の鉄則

全プロンプトに「単一HTML・標準ライブラリのみ・外部CDN/インストール禁止」を添える。事前導入済みの openpyxl/pandas は使ってよい。

困った時（トラブルシュート）

サインインできない
隣とペア／講師画面で確認。Go/Plus/少額APIキーは保険として用意してある。
枠が切れた（残量不足）
アプリの残量表示を確認。会話が長くなったら新しいスレッドを開く。軽い質問はモデルを切り替える。
コマンドが弾かれる
サンドボックス制約による。承認プロンプトで OK を出す（または 代理で承認）。フォルダ外・ネットは要承認。
変なパッケージを提案・生成された
実在を疑う。インストールしない。パッケージ名を検索して確認する（ハルシネーション）。
Excel（.xlsx）が作れない
python -c "import openpyxl" が通るかアプリのターミナル(Cmd+J)で確認し、エラーなら講師に申告。

アプリ操作 早見表

  • 承認モード — 承認を求める / 代理で承認 / フルアクセス / カスタム から選ぶ
  • Review ペイン — 変更を Git 差分で表示。チャンク単位で採用(stage)/取り消し(revert)・コメント・commit
  • ターミナル（Cmd+J） — スレッド内でコマンド実行。出力は Codex も読める
  • Artifacts サイドバー — 計画・生成物（xlsx・HTML等）のプレビュー
  • アプリ内ブラウザ — 生成した report.html をその場で開く
  • スレッド — 新しいスレッドを開く／並列で回す（worktree）
  • モデル選択 — 使用モデルを確認・切り替える（既定 GPT-5.5）

ヒント

ラベルは版で変わる。画面の表示を信頼する。CLI補足：ターミナル派は /approvals（モード）・/diff（差分）・/init（AGENTS.md）・/status（残量）が対応する。

安全チェックリスト

  • 使い捨てフォルダで作業する — 本物の社内リポ・顧客データは絶対に渡さない
  • 秘密を渡さない — APIキー・パスワード・社外秘ファイルを含めない
  • 消費者プランの学習オプトアウトを確認する — chatgpt.com の設定 → データコントロール → 学習に使用しない
  • ネット既定オフのまま使う — その場の pip/npm install や外部CDNは使わない
