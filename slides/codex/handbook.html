インストール（フル手順）

方法①　PowerShell ワンライナー（推奨・Node.js 不要）

PowerShell で実行powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

方法②　npm（Node.js LTS 22+ が必要）

Terminal / PowerShellnpm install -g @openai/codex

方法③　winget

PowerShellwinget install --id OpenAI.Codex

インストール確認

確認コマンドcodex --version

⚠️ よくある間違い

npm i -g codex（スコープ無し）は無関係の別物。winget install Codex -s msstore はGUIアプリで今日のCLIとは別物。確認は必ず codex --version で。

サインイン

通常手順

  1. 作業フォルダで codex を起動する
  2. 「Sign in with ChatGPT」を選ぶ
  3. ブラウザでログインする（普段の ChatGPT アカウント）
  4. /status で残量とモデルを確認する

ブラウザが開けない端末の場合

デバイス認証モードcodex login codex login --device-auth

⚠️ APIキー

APIキーは従量課金。今日は使わない。%USERPROFILE%\.codex\auth.json はパスワード扱い——共有・コミット禁止。

困った時（トラブルシュート）

サインインできない
隣とペア／講師画面で確認。Go/Plus/少額APIキーは保険として用意してある。
枠が切れた（残量不足）
/status で残量を確認。/compact で履歴を圧縮。軽い質問は別モデルに切り替える（/model）。
コマンドが弾かれる
サンドボックス制約による。使い捨てフォルダで Auto モード（/approvals）を使う。
変なパッケージを提案・生成された
実在を疑う。インストールしない。パッケージ名を検索して確認する（ハルシネーション）。
Excel（.xlsx）が作れない
python -c "import openpyxl" が通るかターミナルで確認し、エラーなら講師に申告。

スラッシュ早見表

  • /status — 残量・モデル・プラン情報を表示
  • /approvals — 承認モードを切り替える（Read Only / Auto / Full）
  • /model — 使用モデルを確認・切り替える
  • /review — これまでの変更をレビューする
  • /diff — 現在の差分を表示する
  • /init — AGENTS.md を作成して恒久ルールを設定する
  • /compact — 会話履歴を圧縮して枠を節約する
  • /resume — 前のセッションを再開する
  • /quit — Codex を終了する

安全チェックリスト

  • 使い捨てフォルダで作業する — 本物の社内リポ・顧客データは絶対に渡さない
  • 秘密を渡さない — APIキー・パスワード・社外秘ファイルを含めない
  • 消費者プランの学習オプトアウトを確認する — chatgpt.com の設定 → データコントロール → 学習に使用しない
  • ネット既定オフのまま使う — その場の pip/npm install や外部CDNは使わない

当日朝の講師チェックリスト

  • 無料アカウントで codex サインインが通るか（1台で実機確認）
  • /status の枠表示が正しく出るか
  • 既定モデル名を確認する（/model）
  • 価格・上限を日本円で確認する（chatgpt.com/pricing・chatgpt.com/codex/pricing）
  • python -c "import openpyxl, pandas" が通るか
  • サンドボックスでスクリプト実行が通るか（ネット不要でも弾かれないか）
